# richwords 單字大富翁

給小朋友玩的英文單字大富翁網頁遊戲，單字來自「IEPT 兩岸英語檢定」單字王 500（Part 1、Part 2）。

| 版本 | 檔案 | 收集內容 |
| --- | --- | --- |
| 女孩版 | `girl/index.html` | 5 張團員主題地圖、300 件衣服、50 個髮型 |
| 男孩版（可愛怪獸大富翁） | `boy/index.html` | 5 張屬性地圖、450 隻原創怪獸 |

`index.html` 是選擇版本的首頁。

## 怎麼玩

- **直接打開**：下載後用瀏覽器打開 `index.html`，或是 `girl/index.html`、`boy/index.html`。
- **放到網路上**：在 GitHub 的 Settings → Pages 選 `main` 分支，就會有一個網址可以分享。

每個遊戲都是單一 HTML 檔，不需要安裝任何東西，音樂也是瀏覽器即時合成的。

## 遊戲內容

- **四個關卡**
  - 小朋友：填 1/3 的字母
  - 普通人：填一半的字母
  - 有一點厲害的人：整個單字自己拼
  - 超級厲害的人：英文句子填空，下面有中文翻譯
- **收集**：收集的東西平均分給四個關卡，每個關卡只能拿到自己那一份，要四關都玩才能收齊。遊戲中可以隨時換關卡。
- **地圖**：女孩版有甜點王國、星空舞台、陽光海灘、花園森林、遊樂園五張地圖，每位團員的衣服只在她的地圖拿得到；男孩版有火山、海洋、森林、雷雲、雪山五張地圖，每張的路線和風景都不一樣，屬性怪獸只在自己的地圖抓得到。每張地圖都有捷徑，要剛好停在入口才能選擇要不要走。
- **答題**：用畫面上的字母鍵盤，不會跳出系統鍵盤。每一關都能先聽發音，答錯的字會放進錯字本。
- **存檔**：有 3 個存檔格，每回合自動存檔。

## 注意

- 存檔存在瀏覽器裡（localStorage），換裝置、換瀏覽器或用無痕模式都看不到之前的進度。
- 角色、怪獸和音樂都是原創的。
